Installation & setup

For TVs and TV boxes running Android 7.0 or later.

Download setup guide (PDF, Chinese)

Install with an AI assistant

“Install and open DodoMeow TV. Here’s the APK link and setup guide.”

(If needed, ask your AI agent to help you enable USB or wireless debugging on the TV.)

Install from USB and set up by phone

  1. Copy the APK to USB. Download your edition to a computer and copy it to the drive.
  2. Install on the TV. Open the APK from USB in the TV’s file manager. Allow installation if prompted.
  3. Scan the QR code. On the same Wi-Fi, scan Setup and Guide at the bottom right of DodoMeow TV.
  4. Finish on your phone. Add TV sources or connect a NAS. Set up speech if needed, then save.
