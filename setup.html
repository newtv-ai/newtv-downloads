用 U 盘安装，手机扫码配置

  1. 复制安装包。 在电脑上下载对应版本的 APK，拷到 U 盘。
  2. 在电视上安装。 插入 U 盘，用文件管理器打开 APK。若提示需要许可，按提示允许安装。
  3. 手机扫码。 打开嘟嘟喵TV，让手机和电视连同一个家庭网络，扫首页右下角「设置与说明」二维码。
  4. 配置片源和语音。 在「源管理」添加直播或点播源，在「家庭影库」连接 NAS。按需配置语音，保存后回到电视。

手机扫到模拟器的内部 IP（如 10.0.2.x）打不开时，在 Windows 电脑上解压 ZIP，开启模拟器的 ADB 调试并打开嘟嘟喵TV，再双击 Start NewTV Phone Setup.cmd。让手机和电脑连同一局域网，扫电脑浏览器里显示的二维码。使用时请保持启动窗口打开。无需安装 Node.js。
