隐私政策

最近更新：2026-05-13

嘟嘟喵TV（以下简称"本应用"）非常重视用户隐私。本政策说明在使用本应用过程中可能涉及的信息处理方式。

一、信息收集范围

本应用的核心设计原则是 用户配置数据仅保存在电视本地，不上传服务器。具体如下：

  • 本地存储（不上传）：语音识别 / 大模型 / 语音合成 的用户自有 API 密钥、摄像头连接信息、防沉迷设置、界面偏好。
  • 可选上传（用户授权后开启）：设备运行心跳、客户端错误日志、用户反馈。默认全部关闭。

二、麦克风与摄像头

  • 麦克风音频在本机或用户配置的语音识别服务端处理，不在服务端留存。
  • 摄像头视频流为局域网直连用户自有设备，不经过 嘟嘟喵TV 服务器。

三、未成年人保护

本应用提供"儿童模式"功能，由家长设定每日观看时长上限。未成年人个人信息处理遵循《未成年人保护法》及《未成年人网络保护条例》。

四、第三方服务

本应用集成的可选第三方服务（如讯飞语音、阿里千问、DeepSeek 等）由用户自行配置 API 密钥后使用，相关数据传输由对应服务商负责。嘟嘟喵TV 不代为存储或处理。

五、数据控制权

用户可在配置页随时关闭遥测、清除本地数据。卸载应用后所有本地数据自动清除。

六、联系方式

如有疑问，请通过 GitHub Issues 或邮箱 newtv@mail.grokbot.com 联系。
